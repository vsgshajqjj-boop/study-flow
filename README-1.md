# StudyFlow – مخطط المذاكرة الذكي 📚

تطبيق ويب بيساعد الطالب ينظم مواده ومحاضراته وتسليماته ووقت مذاكرته في مكان واحد.
مشروع مادة Design Thinking – الكلية التكنولوجية بالقاهرة (HITU).

## طريقة التشغيل
الشرح الكامل من VS Code خطوة بخطوة في ملف **RUN_GUIDE.md**.

### أسرع طريقة
1. فك ضغط الملف `studyflow.zip`.
2. اضغط دوبل كليك على `index.html` يفتح في المتصفح (Chrome أو Edge أو Firefox).
3. خلاص! مفيش تثبيت ولا إنترنت ولا سيرفر.

> لتجربة سريعة اضغط **"بيانات تجريبية"** من القائمة الجانبية.

### تشغيل بسيرفر محلي (اختياري)
```bash
cd studyflow
python -m http.server 8000
# افتح http://localhost:8000
```

## المميزات
- **الرئيسية:** إحصائيات + "ذاكر إيه دلوقتي؟" (ترتيب ذكي حسب الأولوية وقرب الموعد) + محاضرات النهاردة + أقرب التسليمات.
- **المهام:** تكليفات / امتحانات / كويزات / مشاريع بأولوية وموعد، مع فلاتر (مفتوحة، متأخرة، منتهية).
- **الجدول:** جدول محاضرات أسبوعي (من السبت للجمعة) باليوم الحالي متظلل.
- **المواد:** كل مادة بلون مختلف.
- **التركيز:** مؤقت Pomodoro (تركيز/استراحة) بيسجل دقايق المذاكرة لكل مادة ورسم بياني لآخر ٧ أيام.
- **تنبيهات:** إشعار قبل التسليم بـ ٢٤ ساعة وقبل المحاضرة بـ ١٥ دقيقة (فعّل الإشعارات من الزر في القائمة).
- **الدليل:** صفحة شرح استخدام سريع جوه التطبيق.
- **رأيك:** تقييم (نجوم + ملاحظات) لاختبار التطبيق مع الطلاب، بيتحفظ مع النسخة الاحتياطية.
- عربي / English، وضع فاتح / داكن، يشتغل على الموبايل.
- **التصدير والاستيراد:** نسخة احتياطية JSON من بياناتك.

## ملاحظات
- البيانات بتتحفظ في المتصفح نفسه (localStorage)، فاستخدم **تصدير** لو عايز تنقلها لجهاز تاني.
- التنبيهات بتشتغل والصفحة مفتوحة في المتصفح.
